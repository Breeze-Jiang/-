# 发现模块｜问答式连续阅读流 v4

## 本轮修正

此前推荐页过度使用工具卡片，未满足用户已提供参考图所要求的“搜索、频道、提示条、标题优先连续帖子流、作者和互动行”的阅读体验。本稿改为以内容流为主体，旅游服务能力嵌入帖子上下文和动作中。

## 固定结构

1. 顶部：品牌入口、搜索框、公开页的“＋发布”。
2. 一级：推荐｜公开；公开被选中时才显示其二级频道“热点旅游资源｜热门标注分享｜旅游计划探讨”。
3. 内容流前：目的地/旅行场景提示条，不使用泛娱乐热榜。
4. 正文：白底连续、细分隔线、标题优先；作者、摘要和紧凑互动行保持一致。
5. 旅游能力：地点资源帖仅显示小型可导航地点行；计划帖显示路线摘要和复制动作；讨论帖不强行伪造地点。

## 非目标

- 不复制任何第三方品牌、图标、文字、排行榜或内容。
- 不把旅游论坛做成图片瀑布流，也不把推荐页做成纯服务卡片墙。
- 不改变已确认的审核、可见范围、按需登录和公开频道语义。
