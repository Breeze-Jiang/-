# 沿途 Logo 字形探索 v1

## 目标

为“沿途”应用图标探索三种不同的中文单字标识方向。三种方案必须都保留完整、可直接读出的“途”字，并使用同一品牌蓝圆角方形底，以便只比较字形气质。

## 固定约束

- 画布：`512 × 512`；圆角 `146`；品牌蓝 `#246BDF`；白色文字。
- 不使用渐变、地图针、路线、山峰、交通工具、额外图形或英文缩写。
- 目标用户为年轻自由行与自驾游客；气质应简洁、高级、耐看。
- 参考仅借鉴“高识别单字中文图标”的简约结构，不复制支付宝、知乎或任何第三方字形和视觉资产。
- 本轮为探索稿；未获用户确认前不得替换当前交接规范中的 v3/v4 基线。

## 三个方向

| 方案 | 字形策略 | 预期气质 | 主要风险 |
| --- | --- | --- | --- |
| A 流线手写 | 使用克制的行楷骨架，强调“走之底”的自然流动 | 有人情味、旅行感强 | 过度书法化会削弱成熟应用感 |
| B 几何字标 | 使用现代无衬线字形，收紧字距并保持方正比例 | 理性、可信、长期耐看 | 过于中性时记忆点不足 |
| C 平衡定制 | 使用人文黑体字形，强调更舒展的整体比例 | 兼具可靠与轻微个性 | 需要避免变回普通系统字 |

## 验收

1. 在大图标和 48 px 图标中，白色“途”字视觉中心均不偏离蓝色圆角方形中心。
2. 三个方向可在同一展示稿中直接比较，且每个单独图标可独立导出。
3. SVG 必须能作为 XML 正常解析。
