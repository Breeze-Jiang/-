# 沿途服务中心设计规格

**日期：** 2026-07-16  
**状态：** 用户已确认，待实施

## 目标

将“沿途服务”从首页的一排弱化标签和混合地点列表，改为旅游便利的独立服务中心。用户应无需理解分类层级，就能从首页快速发现停车、补电、药店、医院、便利店、警务点和美食，并进入对应的距离优先结果与导航闭环。

## 范围

本次只改 Android React Native 前端的地图首页、服务中心与地点结果页信息结构。地点仍使用明确标识的本地演示数据；不新增后端接口、不改变 13 类业务分类，也不接入收藏、论坛或好友功能。

## 信息结构与页面流

1. **地图首页**：厕所、加油站、充电站、超市、景点、酒店继续在首屏直接可见。其下保留高可见“沿途服务”卡片，卡片文案强调“旅行补给与应急”，展示停车场、充电宝、药店、医院四个代表入口，并提供“全部服务”。
2. **沿途服务中心**：点击首页卡片或“全部服务”进入独立页面。页面展示七类完整网格：停车场、充电宝、药店、医院、便利店、警务点、美食；另提供三个快捷分组：自驾补给（停车场、充电宝）、应急求助（药店、医院、警务点）、日常补给（便利店、美食）。
3. **分类结果**：从服务中心的类别或分组进入地点结果页时，页面标题、已选筛选状态与结果必须表达当前类别/分组。单类别只显示该类地点；分组只显示分组包含的类别。禁止“全部服务”无条件返回厕所、加油站等 13 类混合结果。
4. **地点详情与导航**：维持现有地点详情、可信字段和路线选择路径，不因本次页面重构改变导航主动作。

## 交互规则

- 首页服务卡必须可见且不隐藏在三点菜单或普通二级列表内。
- 服务中心中的分类点击进入相应结果；分组点击可在结果页继续切换其包含的分类。
- 结果默认距离优先；营业中、最近确认、设施条件保持现有筛选语义。演示数据必须继续显示“演示地点数据”，不得伪装成实时结果。
- 地图点击收起面板、收起后保留原生地图拖动和缩放的规则不变。

## 视觉规则

- 浅色、蓝色品牌基调，信息密度服务于“十秒找点”，不使用卡通或小程序式大面积装饰。
- 首页服务卡以清晰标题、简洁说明、四个代表入口和明确的“全部服务”动作表达价值；不再将七类服务压缩成难读的单行横向标签。
- 服务中心使用易扫读的图标网格和低干扰分组卡片；结果页优先显示距离、营业时间、最近确认和导航。

## 验收标准

1. 首页可直接发现“沿途服务”，并可从代表入口或“全部服务”进入服务中心。
2. 服务中心可见全部七类服务与三组快捷分组。
3. 点击“停车场”时结果页仅显示停车场；点击“自驾补给”时仅显示停车场与充电宝。
4. 沿途服务入口不会出现厕所、加油站、充电站、超市、景点或酒店的无筛选混合列表。
5. 现有 TypeScript、路由覆盖检查与 Android Release 构建均通过；真机复验首页入口、服务中心、分类结果、返回与导航。
