## 验证证据

- `npx tsc --noEmit`：通过。
- `npx react-native bundle --platform android --dev false ...`：成功输出 Android JS bundle。
- `android/gradlew.bat app:assembleDebug`：已生成当前源码对应的 `place_app/android/app/build/outputs/apk/debug/app-debug.apk`。

## 已知外部依赖

1. Pixel 6 模拟器与 ADB 曾可用，并已捕获一次原生注册名不一致导致的启动崩溃；源码修复已完成，但受桌面内存压力影响，不再以模拟器作为常规验收手段。最新包待以 USB Android 真机优先完成点击验收。
2. `react-native-amap3d` 的 CLI 配置含旧 iOS 字段警告；不阻塞当前 Android APK 打包，但需在地图供应商升级时处理。
3. 页面以本地演示数据保证前端流畅；地点、社区、关系、审核和导航数据需按总规划服务端契约接入。
