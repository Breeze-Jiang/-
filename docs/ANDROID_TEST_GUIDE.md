# 沿途 Android 真机验收清单

测试包：`place_app/android/app/build/outputs/apk/release/app-release.apk`

> 该包为开发签名测试包。安装前若系统拦截，请仅在你自己的测试设备中临时允许安装，不要用于正式分发。

## 1. 启动与游客模式

1. 冷启动应用。
2. 预期：直接进入“地图”，而不是登录页。
3. 依次切换地图、发现、消息、收藏、我的。
4. 预期：地图与发现可直接浏览；消息和收藏显示登录说明；我的显示游客说明。

## 2. 10 秒急需找点路径

1. 在地图页点击“厕所”。
2. 预期：进入厕所结果页，结果按距离展示，显示“演示地点数据”。
3. 打开任一地点详情。
4. 预期：可看到营业时间、最近确认、地点状态与说明；页面不将演示数据称为实时可用。
5. 点击“开始导航”。
6. 预期：可切换步行、骑行、驾车、公交地铁、打车；每种方式均有“使用其他地图”。

## 3. 定位权限

1. 首次进入应用时不要立即授予位置权限。
2. 点击搜索框右侧定位按钮。
3. 预期：此时才出现位置权限请求。
4. 拒绝权限。
5. 预期：进入权限说明页；输入城市、景点或地址后可以继续搜索，不会把拒绝状态显示为已定位。

## 4. 地图交互

1. 在地图首页点击地图区域收起服务面板。
2. 预期：出现“沿途服务”恢复按钮。
3. 尝试拖动、缩放地图。
4. 预期：高德地图可接收手势；若地图未加载，记录网络、系统版本和截图。

## 5. 按需登录与续办

1. 以游客身份打开地点详情，点击“收藏”。
2. 预期：出现登录页；完成测试登录后返回地点详情，并显示“已收藏”。
3. 在发现公开页点击“＋ 发布”。
4. 预期：先登录，完成后进入发布表单。
5. 打开消息或收藏 Tab。
6. 预期：游客先看到解释；登录后可进入消息/收藏资产页。

## 6. 表单与审核

1. 登录后，进入发布、创建标注和创建旅行计划。
2. 不填必填字段直接提交。
3. 预期：显示必填校验。
4. 提交公开内容。
5. 预期：展示审核状态，说明论坛内容审核与地点公开审核是独立流程。

## 7. 同行交流

1. 登录后打开消息中的私聊或“成都周末同行”群。
2. 输入并发送一条消息。
3. 预期：消息立即出现在当前会话中（本地演示状态）。
4. 在群中加入/退出位置共享。
5. 预期：清楚显示成员可退出、发起者退出则整场关闭的规则。

## 8. 外部导航

1. 在路线页点击“使用其他地图”。
2. 分别选择高德、百度、腾讯。
3. 预期：已安装应用优先拉起；未安装时尝试网页回退。记录各设备实际结果。

## 反馈格式

每个异常请提供：设备型号、Android 版本、操作步骤、截图/录屏、出现频率，以及是否可恢复。重点反馈白屏、崩溃、地图无法拖动、权限卡死、返回错误和外部地图无法跳转。
